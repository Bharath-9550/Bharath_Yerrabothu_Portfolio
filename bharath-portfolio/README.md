# Bharath Yerrabothu - Portfolio

A responsive, animated developer portfolio built with plain HTML, CSS, and JavaScript. It has no package dependencies and works fully locally.

## Run locally

From this directory, start a static server:

```powershell
python -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).

You can also open `index.html` directly, though a local server is recommended for consistent browser behavior.

## Update content

- Page content: `index.html`
- Visual design and animation: `style.css`
- Navigation and reveal behavior: `script.js`
- Resume download: `Bharath_Yerrabothu_Resume.pdf`
- Profile photo: add `profile-photo.jpg` in this folder; the built-in placeholder disappears automatically
- LinkedIn: `https://www.linkedin.com/in/bharathraj9/`
- AWS credential: public Credly verification link in `index.html`

Replace the PDF using the same filename to update the resume without changing the page.
